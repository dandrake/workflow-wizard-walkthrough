Installing Python and PyCharm on your own computer

Download and Install Python

Your first step is to download a Python interpreter from the Python website. Your computer may have Python installed on it already, but it is probably good to get an updated version.

Go to the Python Downloads page. Download the current version. Be sure to check that you are downloading an installer that is correct for your operating system, and pay attention to the difference between 32-bit and 64-bit computers when choosing an installer.

Download the proper installer, and double-click on it to run it. Follow the instructions for the installer program.
