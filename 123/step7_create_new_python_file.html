Creating a Python File

Once you have created a project, you can create a Python code file by selecting “New File or Directory…” from the File menu. A menu will appear; select “Python File”. PyCharm will ask for the file name, and then make the file ready for you to edit.

Once you have a file created you should see the file name appear in the left window under the project name. The file can be edited in the right editor window.

To run a Python code file for the first time, you can either select Run… from the Run menu or, if you have an editor window open for the file, you may right-click on the blank space in the editor window and select Run <filename> from there. A Run window should appear at the bottom of the window. Controls for stopping and re-running the program appear at the left edge of the Run window. After the first run, you can re-run the program using the methods already described, or by clicking on the green arrow at the left edge of the Run window, or by clicking on the green arrow in the upper right corner of the whole window.
