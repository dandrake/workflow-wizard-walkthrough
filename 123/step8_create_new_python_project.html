Creating a new Python Project

You probably don’t want to put all of your python files into the same project. To create a new python project after your first, select “New Project…” under the File menu. This will take you back to this new Project window.

You will need to enter a new name for your project in the “Location” box. Again, you do NOT want the “Interpreter type” to be “Project venv”. Switch the “Interpreter type” to “Custom environment”. Then make sure “Environment” has “Select existing” selected. “Type” should have “Python” selected from the dropdown menu. And the “Python path” should have “Python 3.13” selected. Since you have already done this once, it should know where python is, but if not, see instructions above on how to find “Python 3.13” on your machine if it’s not an option from the drop down menu.

Then click the “Create” button in the bottom right corner. A pop-up window may appear asking how you want to Open the new project. If you select “This Window” it will replace the current project you are working on. If you select “New Window” it will open a second Pycharm window with the new project.
